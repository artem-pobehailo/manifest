# Manifest

У цьому проекті додано модальне меню (модалку).

## Де знаходиться модалка

- `index.html`
  - HTML-розмітка модалки знаходиться в блоці `<div class="backdrop">` з дочірнім `<div class="modal">`.
  - Всередині модалки розташовано `nav.modal-nav` та список посилань `ul.modal-list`.

- `script.js`
  - Логіка відкриття/закриття модалки виконується за допомогою кнопки з класом `menu-icon`.
  - При натисканні додається/видаляється клас `is-open` на `.backdrop`.
  - Також додається/видаляється клас `no-scroll` на `document.body`.

- `style.css`
  - Стилі для модалки описані для селекторів `.backdrop`, `.backdrop.is-open`, `.modal`, `.modal-list`.

## Коротко

Модалка використовується для мобільної навігації та знаходиться у файлах `index.html`, `script.js` і `style.css`.
